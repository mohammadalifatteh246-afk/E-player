- **Hermes Agent & Skills**: Hermes agent bridge and CLI runtime, specialized skills in YAML frontmatter + markdown format. 66 enabled skills active.
- **Distribution & Storage**: `D:\Agents workespaces` (Sectors: Core Coding, Research, QA, etc.) and `D:\overload` with 100% cryptographic SHA256 parity.

# E-PLAYER STITCH PROMPT PACK

## MASTER PROMPT
Create a premium mobile-first dark multimedia player UI named E-Player. Use `.stitch/DESIGN.md` as the mandatory source of truth. Use the approved E-Player visual reference as the visual anchor. Deep navy base, electric cyan/blue primary, purple/magenta AI accents, cinematic imagery, rounded cards, subtle glow, modern typography. Product positioning: offline-first, privacy-first, AI-enhanced, universal media player. Do not create a generic SaaS dashboard.

## HOME
Create E-Player Home: compact app bar with logo/search/settings; Continue Watching hero; Recently Added rail; categories; favorites; bottom navigation Home/Library/Enhance/Cast/Settings. Optimize for one-handed mobile use.

## PLAYER
Create an immersive E-Player video player: maximum media area; top-left back; top-right cast/more; center play/pause; bottom seek bar/time/core controls; audio/subtitle/enhance actions; subtle gradient controls; auto-hide friendly. Keep the player uncluttered.

## ENHANCEMENT STUDIO
Create E-Player AI Enhancement Studio with AI switch; Video/Audio tabs; Auto/Manual/Preset; model selector; 720p/1080p/1440p/2160p/4K; RIFE; Night Mode; 2D→3D; Apply/Preview/Export. Use purple only for advanced AI accents, while primary actions remain blue/cyan.

## LIBRARY
Create E-Player Media Library with search; All/Videos/Audio/Folders filters; two-column media grid; thumbnail badges; progress/favorites; scan/add action; bottom navigation.

## SETTINGS
Create E-Player Settings with Playback, Audio, Subtitles, Gestures, AI Enhancement, Library, Privacy, Network & Cast, Storage, About. Each row uses icon + title + value/description + control/chevron.

## DECODER
Create Decoder Mode bottom sheet: Auto / Hardware / Hardware+ / Software. Show actual decoder backend, codec and fallback note.

## EQUALIZER
Create five-band E-Player Equalizer with Normal/Rock/Pop/Classical/Jazz/Movie/Dialogue/Custom presets, Bass Boost, Virtualizer, Dialogue Boost, Night Mode, Limiter.

## SUBTITLE
Create Subtitle Settings with track selector, online search, delay, font size, colors, outline, position, encoding, live preview.

## GESTURES
Create Gesture Settings with volume, brightness, seek, double-tap, pinch zoom, two-finger speed; toggles and sensitivity values.

## VAULT
Create a calm premium Privacy Vault with lock status, biometric, auto-lock, protected file count, import and restore. Use shield/lock visual language.

## CAST
Create Cast & Network screen with Network Stream/Cast tabs, URL+Open, recent streams, device discovery, connection state and controls.

## PERFORMANCE
Create Performance & Hardware screen showing FPS, Decoder, AI Provider, CPU, Memory, GPU, Thermal and AI State in an understandable technical layout.

## VARIANT RULE
Keep layout hierarchy, brand, typography and spacing consistent. Variants may change emphasis, density or media composition, but must not introduce a new design language.
